# Parkinsons_Data_Visualizations

Parkinson’s disease is a progressive neurodegenerative disorder characterised by motor impairments measured using the MDS-UPDRS Part III (NP3) scale. Understanding how motor severity relates to cognitive function and demographic factors may improve patient stratification and clinical management. However, the underlying structure and relationships among motor symptoms remain complex. This study aims to explore motor severity, symptom patterns, and their associations with cognition and age using statistical and multivariate techniques.
